## 再実行

```sh
# 公開環境: ローカルサーバーを起動せず、指定URLを検査
PLAYWRIGHT_BASE_URL=https://warica.vercel.app pnpm test:e2e --workers=2

# ローカル: 本番向けビルドを検査
pnpm build
pnpm test:e2e
```

`PLAYWRIGHT_BASE_URL` を指定した場合は、既存操作テストとアクセシビリティ検査の両方がそのURLを使います。アクセシビリティの詳細結果はテストレポートのJSON添付で確認できます。
